# RDL Sowa City

**奏和市（そうわし）**は、RDLを都市・統治・幸福・文化・個人・集団・環境・死生観へ同時適用したとき、どこまで一つの有限な関係動態として扱えるかを検討する思考実験です。

> **RDL最大射程の幸福維持統治・社会構造思考実験。**

奏和市は「全知AIが上から管理する理想都市」を想定しません。

人間、金属族、文化、地区、習慣、都市環境、自然、インフラ、歴史、そして調整機構であるプラクシスも、すべて奏和市という関係構造の内部にあります。

```text
奏和市
├─ 人間
├─ 金属族
├─ 地理・環境
├─ 文化・習慣
├─ 地区・共同体
├─ インフラ
├─ 死生観・儀礼
├─ 蓄積された履歴
└─ プラクシス
```

プラクシスは広い観測・調整能力を持ちますが、都市の外部に立つ主権者ではありません。

```text
Praxis constrains the city
and
The city constrains Praxis
```

プラクシス自身も、設計時に与えられた目的・禁止条件・能力限界、現在の有限な観測境界、都市に蓄積した文化・履歴・関係から拘束を受けます。

## 位置づけ

このリポジトリは `RDL_Core` の意味論上の権威ではありません。

```text
RDL_Core
= 基底措定・最低動作仕様・T1操作・共有語彙

RDL_Sowa_City
= それらを社会・都市・統治へ大きく適用する思考実験
```

奏和市固有の用語・制度・仮説をCore primitiveへ自動昇格させません。

また、奏和市自身もRDLの自己例外ではありません。

```text
finite B
→ finite description / intervention
→ ξ(B) != 0
→ local stability != terminal closure
```

## 中心課題

奏和市が主に扱う問いは次のようなものです。

- 幸福を静止状態ではなく、維持・再調整される関係動態として扱えるか。
- 強制や暴力への依存を減らしながら、破滅的な構造破断を避けられるか。
- 局所的不整合・失敗・対立を消さずに、全体破綻への接続だけを弱められるか。
- 人間の主体性を残したまま、環境・制度・関係配置による調整を行えるか。
- 大きな調整能力を持つプラクシス自身を、都市構造の外部へ例外化せず扱えるか。
- 幸福維持そのものが新たな拘束・支配・停滞を生まないか。
