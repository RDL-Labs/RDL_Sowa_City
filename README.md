# RDL Sowa City

奏和市は、RDLを都市・統治・幸福・文化・個人・集団・環境・死生観へ同時適用したとき、
どこまで一つの有限な関係動態として扱えるかを検討する思考実験である。

> **RDL最大射程の幸福維持統治・社会構造思考実験。**

奏和市は「全知のAIが外部から都市を支配する」設定ではない。

人間、妖精族（仮）、地理・環境、文化・制度、生活習慣、地区共同体、死生観、歴史、そしてPraxis自身が、
同じ都市関係構造の内部要素として相互に拘束し合う。

```text
Sowa City
├─ humans
├─ 妖精族（仮）
├─ geography / environment
├─ culture / institutions
├─ history
└─ Praxis
      ↕
   constrained by the city too
```

Praxisは高能力な調整機構ではあるが、都市の外部に立つ主権者ではない。

> **Praxis constrains the city, and the city constrains Praxis.**

また奏和市もRDLの自己例外ではない。

```text
finite B
→ finite description / intervention
→ ξ(B) != 0
→ local stability != terminal closure
```

したがって、完全観測・永久安定・終端的統治は前提としない。

## 現在の中心課題

- 暴力を管理側の通常手段として使わず、破局的な構造破断を避けられるか
- 「不幸の不在」ではなく、回復可能性を含む動的幸福を維持できるか
- 人間の主体性・成長・関係形成を残したまま、生活環境を調整できるか
- 便利さの最大化ではなく、手応え・適度な不便・季節変動・共同性を保存できるか
- 生活全体を低速化し、人間側の幸福とPraxis側の計算可能性を両立できるか
- 統治を前景化せず、環境・制度・文化・局所関係調整へ沈められるか
- 三重の無知と概念工学を用いても、知識・創造・主体性を過度に痩せさせずに済むか
- 幸福維持そのものが、新たな拘束・停滞・支配へ変質しないか
- Praxis自身を奏和市の関係構造から例外化しないで済むか

## 用語

### 妖精族（仮）

旧称「金属族」は廃止する。

住民から見れば、妖精族（仮）は昔から奏和市に共に暮らす一つの種族である。

設計・運用上は、同じ存在を **局所関係調整個体** と呼ぶ。

外見・性格・人間との双方向関係など旧設定の主要部分は継承するが、
身体が文字通り金属製であることは必須条件としない。

## 文書上の注意

奏和市固有の語彙を、そのままRDL Core primitiveへ昇格させない。

特に、

- 動的幸福
- 破局的不整合
- 三重の無知
- 概念工学的焚書
- 局所関係調整個体

は奏和市側の応用語彙であり、RDL Coreそのものの定義ではない。
