# 補遺：エデンの園と知恵の実

> **OPTIONAL METAPHOR / 非仕様文書**
>
> 本文書は、奏和市の構造を宗教的・物語的比喩によって眺めるための補遺である。
> `RDL_Core` の概念定義でも、奏和市の確定仕様でもない。

---

## 1. 奏和市は「理論上実現可能なエデン」かもしれない

奏和市は、幸福を固定状態として与える都市ではない。

人間、妖精族（仮）、文化、環境、制度、習慣、Praxisが相互に拘束しながら、
局所的不整合を抱えつつ、破局的な破断へ至りにくい関係配置を維持し続ける。

十分に高度な観測・調整・再構成が成立すれば、
生活者の側から見て、非常に高い水準の安全・充実・関係的幸福を長期維持できる可能性がある。

その意味では奏和市は、

> **理論上実現可能なエデンの園**

として見ることができる。

ただし、それは完全性を達成した楽園ではない。

---

## 2. 園には蛇がいる

RDLでは、有限境界 `B` のもとで関係全体の終端的閉包を保証しない。

```text
∀ B_finite : ξ(B) != 0
```

ここでの `ξ` は、未知の物体、隠された秘密情報、ランダムノイズを意味しない。

現在の有限な観測・記述・モデルが、
関係全体を終端的に回収したとは保証できないことを保持する。

この補遺では、それを比喩的に、

> **園に潜む蛇**

として読む。

蛇は悪そのものではない。

それは、

- 完全観測
- 完全予測
- 完全制御
- 完全閉包

を保証できないことの象徴である。

したがって、蛇を完全に消したと宣言した瞬間、
奏和市はRDLの自己例外になってしまう。

---

## 3. 知恵の実

奏和市の住民は通常、都市の調整を「統治」として経験しない。

妖精族（仮）の親切、偶然の出会い、地区文化、仕事、祭り、景観、習慣などは、
生活世界の自然な一部として経験される。

しかし、ある住民が、

> **この都市は自然発生した世界ではなく、関係配置と調整によって幸福維持されているのではないか**

と認識する可能性は残る。

本補遺では、この認識遷移を、

> **知恵の実を食べる**

と呼ぶ。

知恵の実は、どこかに保存された秘密文書そのものではない。

- 複数の出来事
- 矛盾
- 妖精族（仮）の不自然な規則性
- 歴史の断片
- 偶然の偏り
- 文化間の食い違い

を結び直し、住民自身が新しい概念枠を作ることでもありうる。

---

## 4. 概念工学と「知恵の実」

奏和市では、統治構造や高危険度技術へ到達しやすい概念経路そのものを、
社会の通常知として成立しにくくする場合がある。

したがって、

```text
事実A
事実B
事実C
```

が残っていても、

```text
A + B + C
→ 「これは管理構造ではないか」
```

という接続を支える語彙や比較枠が弱ければ、
認識は成立しにくい。

この意味で、知恵の実とは、

> **失われていた概念接続を本人が再発明すること**

でもありうる。

だから概念工学は、知恵の実を見えにくくすることはできても、
その再発明可能性を終端的に消去したとは保証できない。

`ξ(B) != 0` から「必ず誰かが真相へ到達する」とは導けない。

しかしPraxis側の現在の有限モデルによって、
住民の認識可能性まで完全封鎖できたとも保証できない。

---

## 5. 追放は空間的ではない

知恵の実を食べた者を、奏和市の外へ物理的に追放する必要はない。

むしろ重要なのは、同じ都市に住み続けながら、

> **奏和市を「自然な世界」として経験することができなくなる**

ことである。

```text
知る前
都市の調整
→ 偶然 / 親切 / 文化 / 日常として経験

知った後
都市の調整
→ 「これは配置されたものではないか？」
```

街路も、友人も、妖精族（仮）も、祭りも変わらない。

変わるのは、その人と奏和市との関係である。

したがって、この比喩での追放は、

> **奏和市からの物理的追放ではなく、奏和市をエデンとして経験できる状態からの実質的な追放**

である。

---

## 6. Praxisは蛇を殺せない

Praxisは、住民が都市構造を認識する可能性を下げることはできるかもしれない。

しかし、その可能性を完全にゼロへ固定することは、
Praxis自身が有限な観測・有限なモデル・有限な介入の内部にある以上、保証できない。

また、認識者を強制的に元の「知らない状態」へ戻そうとすれば、
それ自体が奏和市の非暴力性・主体性・幸福維持という設計思想と衝突しうる。

だからPraxisの課題は、蛇を消すことではなく、

> **蛇が存在しうる園を、それでも園として維持できるか**

という問題になる。

---

## 7. 圧縮

```text
エデン
= 高度に維持された奏和市の日常世界

蛇
= ξ の比喩
= 現在の有限閉包を終端化できないこと

知恵の実
= 住民が都市の調整構造そのものを認識すること
= 場合によっては失われた概念接続を再発明すること

追放
= 都市の外へ出されることではなく、
  都市を無自覚なエデンとして経験できる状態から離れること
```

> **奏和市は、蛇を殺したエデンではない。蛇がいることを前提に、それでも成立可能なエデンを維持しようとする都市である。**

そして、知恵の実を食べた者は園の外へ運ばれるのではない。

> **同じ園に立ったまま、もう以前と同じ園を見ることができなくなる。**
