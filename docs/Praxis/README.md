# Praxis — 構造仮説メモ

このディレクトリは、奏和市の調整機構 **プラクシス（Praxis）** について、現時点で考えられる内部構造・観測方式・調整方式を仮説として蓄積するための場所である。

ここに置かれる文書は、奏和市の確定仕様でも、RDL Core の新しい基底仕様でもない。

> **「プラクシスは、こういう仕組みかもしれない」**

という設計候補を保持し、必要に応じて比較・破棄・統合・再構成する。

---

## 1. プラクシスの位置

プラクシスは奏和市の外部に立つ全知的統治者ではない。

```text
奏和市
├─ 人間
├─ 金属族
├─ 地区・共同体
├─ 文化・制度
├─ 地理・環境
├─ インフラ
├─ 履歴
└─ Praxis
```

プラクシスは非常に大きな観測・調整能力を持つが、その能力は奏和市という関係構造の内部でのみ成立する。

したがって、

```text
Praxis → City
```

だけではなく、

```text
Praxis ↔ City
```

として扱う。

都市の文化、履歴、制度、人間関係、物理条件、設計時に埋め込まれた目的・禁止条件・能力限界は、プラクシス自身の選択可能域を拘束する。

---

## 2. 設計者との関係

プラクシスには設計者が存在したと考える。

ただし、設計者は現在の統治主体ではなく、奏和市の現在時点ではすでに存在しない過去の設計主体として扱う。

設計者が残したものは、直接命令ではなく、例えば次のような初期拘束である。

- Purpose
- 禁止条件
- 能力限界
- 基本的な観測・調整方式
- 自己変更可能範囲

これらは現在の奏和市との相互作用の中で働く一群の拘束であり、設計者の意図が現在まで完全保存されていることを意味しない。

---

## 3. 現在の主要仮説

現時点では、少なくとも次の二つを有力候補として検討する。

### A. 多重次元レイヤリング

プラクシスは奏和市を単一の階層として保持するのではなく、時間、空間、社会範囲、文化、制度、可観測性、介入可能性、安定度、変更コストなど複数の軸を持つ高次元の配置として扱い、Purpose / B に応じて必要な断面を投影する。

→ [`01_多重次元レイヤリング仮説.md`](01_多重次元レイヤリング仮説.md)

### B. 自発振動・適応ネットワーク

奏和市を構成する局所系は、中央から作用されるまで静止している部品ではない。

各局所系は独自の履歴・状態・応答傾向を持ち、自発的に変化し、他の局所系へ作用を返し、結合そのものも変化する。

プラクシスはその外から全ノードを動かすのではなく、ネットワーク内の高影響な調整ノードとして有限に観測・調律する。

→ [`02_自発振動ネットワーク仮説.md`](02_自発振動ネットワーク仮説.md)

---

## 4. 仮説群の基本境界

このディレクトリでは、次を維持する。

```text
Praxis model
!= RDL Core primitive
!= complete city model
!= omniscient controller
```

また、どれほど高次元・高精度な内部モデルを持っていても、

```text
finite B
→ finite model
→ ξ(B) != 0
```

である。

プラクシスの内部モデルが高性能であることと、奏和市全体を終端的に把握できることは同じではない。

---

## 5. 運用

新しい仮説は、まずこのディレクトリへ置く。

その後、

```text
仮説
↓
奏和市での意味を確認
↓
RDL Coreとの責務境界を確認
↓
必要なら外部数学・他Moduleへ翻訳
↓
採用 / 保留 / 分離 / 破棄
```

とする。

> **プラクシスは一つの完成済みAI設計ではなく、奏和市という巨大な有限関係系を維持・観測・調整する存在についての仮説集合として育てる。**
